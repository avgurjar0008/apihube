# APIHub — Phase 1

Discover. Understand. Test. Build.

Phase 1 includes a React/Vite frontend and Node/Express backend with a working API request workspace.

## Run
Backend:
cd backend
npm install
npm run dev

Frontend:
cd frontend
npm install
npm run dev

Backend: http://localhost:5000
Frontend: http://localhost:5173

Do not enter real passwords, private tokens, API secrets, or other sensitive credentials in this development build.
